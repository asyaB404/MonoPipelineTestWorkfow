# Windows 普通包黑盒规则

<!-- 创建日期：2026-10-09；创建人：Cyou；功能：普通 PC 包黑盒的准备、安全和观察门槛；参数：显示基准、模板、区域、OCR、输入许可。 -->

黑盒 = 不读取包内对象，仅使用可见画面与系统输入。实现为原生 Windows 接口、本地 OpenCV 图像匹配及可选 Tesseract OCR（图像文字识别），没有引入 Airtest 强制依赖；不会注入游戏、重新打包、安装依赖、下载模型或回退云端。

## 准备

- 读取 [`PC功能测试使用说明.md`](../../../../Doc/AI开发文档/PC功能测试使用说明.md) 的黑盒配置表；用例、模板和验收条件必须对应实际包、语言及显示基准。示例配置只供准备与纯校验，不能当作已采集的游戏模板。
- 目标必须位于本机解锁的交互桌面，保持前台、无遮挡、客户区完整处于同一显示器。客户区 = 不含标题栏/窗口边框的游戏画面区域；ROI = 客户区内四个整数表示的横坐标、纵坐标、宽、高。
- 按实际客户区配置尺寸和 DPI（显示缩放密度），当前采用严格 1:1 物理像素。移动、缩放、跨显示器或窗口重建后本轮停止，不自动换算或重试。
- 缺少真实画面时，可用独立受控采集入口 [`pc_prepare_capture.py`](../../../../Tools/AI/pc_prepare_capture.py) 对显式目标客户区单次采集一帧 BMP 与准备 JSON，作为定位资料；它不启动/登录/切页/抢焦点/输入，无 `--allow-capture` 或 `--plan-only` 时只做参数与本地路径校验。该采集**只证明**目标客户区能采到一帧非黑屏/低对比画面，**不证明**界面稳定、**不证明** ROI 可用、**不构成**业务结论；模板 ROI、页面锚点与正负阈值仍需协调者基于授权资料整理并在真实窗口校准，不因采到一帧就声称模板可用。
- 启用模板断言必须提供目标和独立页面锚点；相同路径/ROI 的别名在纯校验时拒绝，相同内容/ROI 的复制文件在启动前拒绝，运行中目标与锚点命中同一位置也无法判定。启用文字断言必须额外提供显式本地 OCR 程序、语言模型目录、语言、分割模式及置信度。所有声明资源在启动目标前预检；缺依赖记录环境阻塞，不临时安装。

## 执行

- 支持的方法和字段以 [`METHODS`](../../../../Tools/AI/functiontest_runtime/blackbox.py:134) 与 [`validate_config()`](../../../../Tools/AI/functiontest_runtime/blackbox.py:140) 为准；不开放 shell、组合键、剪贴板、持续按键或任意脚本。
- 绑定指定进程的唯一可见窗口。标题仅过滤候选，不替代程序路径、创建时间和窗口身份。不得自动选择其他进程或第一个候选窗口。
- 取得会话级命名互斥后，每次采集/输入检查身份、锁屏、前台、遮挡、尺寸与新鲜度。不抢焦点、不恢复最小化窗口、不关闭未知弹窗。人工或其他程序仍可能在最后检查后抢占全局输入，互斥不能保证操作系统级原子送达。
- 每个输入动作前用两张新帧验证局部区域稳定，仅发送一次输入并成对释放。文本输入失败可能留下部分文字，不重放。每个动作后由公共计划执行独立断言，输入回执不是通过证据。
- 断言用两次新帧确认页面锚点和目标。明确可信反例才失败；匹配阈值之间、多匹配、空 OCR、低置信度或不稳定观察为无法判定；失焦、黑屏、截图过期和身份变化为阻塞并停实例。
- 截图以本轮实例私有 BMP（无压缩位图）保存，宿主复制到用例证据并计算摘要。正常执行也会保存断言帧，不受编辑器“每例两张截图”限制；本地文件不自动送给模型。当前无全运行磁盘预算或自动证据清理，长计划先核对空间。

## 使用注意与变更

模板匹配分数不是正确率。素材要用正负样本校准；同一图像附近多个高分候选也可能保守记为歧义。当前只比较文字包含，不支持数值/单位推导。GDI（Windows 图形设备接口）可能无法捕获某些游戏渲染路径；独占全屏、远程会话、网络盘和重解析路径未支持。截图质量不足时不把空画面当产品反例。

只清理本轮创建的进程；附加进程保留。取消只能停止后续步骤并清理输入，不能撤销已发出的游戏操作。2026-10-09：首次加入黑盒实现与隔离安全测试；尚无真实游戏截图、输入、OCR 或连续运行验收，不宣称满足设计计划的十轮实测门槛。
