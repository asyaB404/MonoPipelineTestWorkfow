# 输入纠正与来源中断

## 初始化前

`output-check` 只读接收候选输出/功能前缀，计算实际 case 摘要目录、证据类别、随机标识及扩展名的 UTF-16 路径预算；Windows 文件上限 259 单元，非 BMP 字符计 2 单元。超限退出 3，不建目录或接触 Player；`init` 在创建本轮根前执行同一检查。

Agent 在已批准范围选短根；新增输出范围只确认真实范围，统计模式保留原功能/随机子根规则。预检失败尚无实际轮次，不能据此将既有冻结轮换根续行；不改系统长路径设置。

## 草稿与已发送请求

按 `start-case/status` 返回的原文显式索引整理，不把数组位置当索引；各范围绑定见[宿主契约](host-contract.md)。`request-check` 不登记/写事件/连接 Player，`request-publish` 检查后独占发布新文件、不发动作。未登记的错误草稿可以修改；已登记文件不可改写或删除，后续更正须新文件和新 ID。

已发送请求只有在真实编译诊断明确未执行时才能按原步骤/目标关联更正，保留 `correction_of` 等原约束；同一 ID 不重放。新包装仅在身份已验证时将只读 `return_value_contract:*` 隔离到本例，保留成功执行回执和无效观察，真实收口后继续未开始例；严格只读 `script_failed` 同样处理。动作/探针、未知阶段、超时、断连、身份/协议异常仍停止整轮，不重试、终止代码或重新附加；旧不可靠信封不能追认成受控错误。

## 来源失效后的本地终止

外部用例、许可、请求或基线变更/删除时，业务和正式审计仍拒绝。私有快照、摘要链及头锚有效时，`status` 可显示冻结/来源无效，`close` 使用新请求文件写明确中断原因；不修改原来源以求解冻。

此分支只核验私有证据，保留已有 final/缺例，追加唯一来源中断、无效审计与关闭事件，闭合真实 writer 计时并生成固定诊断摘要。不新增 final、不接触 Player、不声称代码已终止。恢复外部原字节也不恢复业务/正式报告；诊断摘要不是测试报告，不转换统计或上传，摘要本身仍验大小与原摘要。

父收到正式资格为否后，结束实际子/父计时并交诊断，不继续普通 audit/report、reference 或统计。独立包内父可核验无效子真实终止后关闭，但正式父报告仍拒绝。私有快照、头锚、运行身份或父起点损坏不在此例外，继续拒绝。

## 宿主修复后的新轮

只限已确认的包外宿主缺陷：修复有负向对照的回归且全量通过，交付清单显式刷新；旧轮以真实原因关闭；用户明确同意另开新轮。三项齐全后从共享链路重新留证，不迁移旧结论，不假设旧动作副作用消失。产品/环境中断、未知动作或失效来源不能借此恢复或重放。

回归入口及分层范围见[隔离验证](isolation-tests.md)；具体历史失败/通过次数留在维护日志，不作为当前操作步骤。
